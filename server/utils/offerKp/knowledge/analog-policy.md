# Политика аналогов (OfferKP)

Код-истина: `analogRules.js` + `matchInquiryLines.js` (exact/analog → цена). Markdown — подсказка для LLM-fallback, не защита.

## Разрешено как analog (с ценой ShopDB)

- Тот же тип изделия (болт/гайка/шайба/винт/штифт…).
- Эквивалент стандарта DIN ↔ ГОСТ/ISO из правил (см. `din-gost-equivalents.md`).
- Размеры M×L (или диаметр) **совпадают**.
- Покрытие и класс прочности совместимы или явно согласованы правилом.

## Запрещено подставлять цену

- `similar` / `size_mismatch` / `spec_mismatch` / `none` — только подсказка «похожий», цена = пусто / «под заказ».
- Неполный размер в заявке (нет M или длины) — abstain, даже если кандидат найден.
- Расхождение lexical vs embedding top-1 на exact — требует проверки оператора.

## Golden set

Override указывает SKU; **цена всегда** из живого `searchByExactSku`, не из CSV.
